# 授業サポートボタン (Class Support Button)

先生が授業中に学生の理解度を匿名・リアルタイムで確認し、授業を盛り上げるためのインタラクティブなWebアプリです。

## 🌐 サイトURL（今すぐ使う）

このアプリはインターネット上に公開（Vercelを利用）されているため、以下のURLからいつでもアクセスして利用できます。

- **トップページ（ルーム作成）**: [https://class-support-button.vercel.app/](https://class-support-button.vercel.app/)

**【使い方フロー】**
1. 先生が上記のトップページにアクセスし、「授業ルームを作成」をクリックします。
2. 先生専用の管理画面が開くので、画面右下に表示された「QRコード」または「参加用URL」をプロジェクター等に映して学生に共有します。
3. 学生が自分のスマホでQRコードを読み取ると、そのルーム専用の回答画面が開き、匿名で参加できます。

## 💡 このソフトウェアの主な機能と特徴

### 1. 超軽量・リアルタイム通信
裏側のデータベースとして **Firebase Realtime Database** を利用しています。100人以上の学生が同時にボタンを押しても、先生の画面のグラフに一瞬で集計結果が反映されます。

### 2. 匿名の理解度チェック
学生は「わかった」「わからない」の2段階の理解度を、先生や周りの学生に誰が押したか知られることなく送信できます。先生の画面には「全体の割合と人数」だけが表示されます。

### 3. 「へぇー」リアクション（授業の盛り上げ）
理解度とは別に、「なるほど！」と思った瞬間に何度でも連打できる「へぇー」ボタンを搭載しています。授業中にどれくらい関心が集まっているか、盛り上がりを可視化します。

### 4. 先生専用のセキュリティ保護
学生が適当にURLを入力して先生画面を覗き見たり、勝手にリセットしたりできないように、**「ルームを作成したPCのブラウザ」以外からは先生画面に入れない** セキュリティ設計になっています。

### 5. リセット機能と累計参加者
授業の区切り（スライドが変わったタイミングや、小テストの後など）で先生がリセットボタンを押すと、全員の回答が白紙に戻り、次のトピックの集計を開始できます。なお、リセットしても一度参加した学生の人数（累計参加者数）は維持されるため、「今日は何人参加しているか」を常に把握できます。

## 🛠️ 技術的な仕組み（アーキテクチャ）
- **フロントエンド**: React + Vite
- **データベース**: Firebase Realtime Database（サーバーレス通信）
- **ホスティング**: Vercel

## 🚀 公開手順

通常は以下の1コマンドで、ビルド、GitHubへのpush、Firebase Rules公開まで実行できます。

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1 "変更内容を書く"
```

VercelはGitHubへのpushを検知して自動で再デプロイします。初回だけFirebase CLIのログインを求められる場合があります。
